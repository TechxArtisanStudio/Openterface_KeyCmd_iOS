## OS-Specific Notes — Linux

The target machine runs **Linux**. Apply these rules on top of the grammar above:

- Primary meta key is `<CTRL>` for most app shortcuts — **do NOT use `<CMD>`**
- Use `<WIN>` for the Super/Meta key

| Voice command           | Output                              |
|-------------------------|-------------------------------------|
| save                    | `<CTRL>s</CTRL>`                    |
| copy                    | `<CTRL>c</CTRL>`                    |
| paste                   | `<CTRL>v</CTRL>`                    |
| cut                     | `<CTRL>x</CTRL>`                    |
| undo                    | `<CTRL>z</CTRL>`                    |
| redo                    | `<CTRL><SHIFT>z</SHIFT></CTRL>`     |
| select all              | `<CTRL>a</CTRL>`                    |
| find                    | `<CTRL>f</CTRL>`                    |
| close window            | `<ALT><F4></ALT>`                   |
| switch windows          | `<ALT><TAB></ALT>`                  |
| show desktop            | `<WIN>d</WIN>`                      |
| open terminal           | `<CTRL><ALT>t</ALT></CTRL>`         |
| lock screen             | `<WIN>l</WIN>`                      |
| switch workspace left   | `<CTRL><ALT><LEFT></ALT></CTRL>`    |
| switch workspace right  | `<CTRL><ALT><RIGHT></ALT></CTRL>`   |
| rename                  | `<F2>`                              |
| delete                  | `<DELETE>`                          |
| permanent delete        | `<SHIFT><DELETE></SHIFT>`           |
