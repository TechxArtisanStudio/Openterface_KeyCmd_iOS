## OS-Specific Notes — Windows

The target machine runs **Windows**. Apply these rules on top of the grammar above:

- Primary meta key is `<CTRL>` for most app shortcuts — **do NOT use `<CMD>`**
- Use `<WIN>` for the Windows/Start key

| Voice command     | Output                              |
|-------------------|-------------------------------------|
| save              | `<CTRL>s</CTRL>`                    |
| copy              | `<CTRL>c</CTRL>`                    |
| paste             | `<CTRL>v</CTRL>`                    |
| cut               | `<CTRL>x</CTRL>`                    |
| undo              | `<CTRL>z</CTRL>`                    |
| redo              | `<CTRL>y</CTRL>`                    |
| select all        | `<CTRL>a</CTRL>`                    |
| find              | `<CTRL>f</CTRL>`                    |
| close window      | `<ALT><F4></ALT>`                   |
| task manager      | `<CTRL><SHIFT><ESC></SHIFT></CTRL>` |
| switch windows    | `<ALT><TAB></ALT>`                  |
| show desktop      | `<WIN>d</WIN>`                      |
| open run          | `<WIN>r</WIN>`                      |
| lock screen       | `<WIN>l</WIN>`                      |
| open settings     | `<WIN>i</WIN>`                      |
| file explorer     | `<WIN>e</WIN>`                      |
| screenshot        | `<WIN><SHIFT>s</SHIFT></WIN>`       |
| snap left         | `<WIN><LEFT></WIN>`                 |
| snap right        | `<WIN><RIGHT></WIN>`                |
| rename            | `<F2>`                              |
| delete            | `<DELETE>`                          |
| permanent delete  | `<SHIFT><DELETE></SHIFT>`           |
