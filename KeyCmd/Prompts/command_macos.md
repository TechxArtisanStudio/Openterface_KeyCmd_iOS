## OS-Specific Notes — macOS

The target machine runs **macOS**. Apply these rules on top of the grammar above:

- Primary meta key is `<CMD>` for most app shortcuts — **do NOT use `<WIN>`**
- `<ALT>` = Option key

| Voice command      | Output                            |
|--------------------|-----------------------------------|
| save               | `<CMD>s</CMD>`                    |
| copy               | `<CMD>c</CMD>`                    |
| paste              | `<CMD>v</CMD>`                    |
| cut                | `<CMD>x</CMD>`                    |
| undo               | `<CMD>z</CMD>`                    |
| redo               | `<CMD><SHIFT>z</SHIFT></CMD>`     |
| select all         | `<CMD>a</CMD>`                    |
| find               | `<CMD>f</CMD>`                    |
| quit app           | `<CMD>q</CMD>`                    |
| close window       | `<CMD>w</CMD>`                    |
| minimize           | `<CMD>m</CMD>`                    |
| spotlight          | `<CMD><SPACE></CMD>`              |
| force quit         | `<CMD><ALT>Escape</ALT></CMD>`    |
| screenshot region  | `<CMD><SHIFT>4</SHIFT></CMD>`     |
| screenshot full    | `<CMD><SHIFT>3</SHIFT></CMD>`     |
| lock screen        | `<CMD><CTRL>q</CTRL></CMD>`       |
| switch apps        | `<CMD><TAB></CMD>`                |
| mission control    | `<CTRL><UP></CTRL>`               |
| move to trash      | `<CMD><BACK></CMD>`               |
| rename             | `<ENTER>`                         |
